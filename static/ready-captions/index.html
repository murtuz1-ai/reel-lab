Без ключа работает запасной бесплатный генератор: он медленный и часто успевает нарисовать только 1–2 картинки. С бесплатным ключом Cloudflare — быстро, красиво и около 10 роликов в день.
ИИ читает текст…

ИИ прочитает текст, подсветит главные слова по смыслу и нарисует к ним картинки.

Слова и картинки двигаются прямо на видео: поставь на паузу, нажми и тяни. Угол рамки — размер, «Вперёд» — картинка перед текстом, «Вся фраза» — двигать фразу целиком.

Голос из видео

Ключ ИИ

Картинки рисует нейросеть FLUX, а слова подбирает ИИ-режиссёр в Cloudflare Workers AI. Бесплатно — примерно 10 роликов в день, дальше около цента за ролик. Ключ хранится только на этом компьютере.

  1. Зарегистрируйся на dash.cloudflare.com — бесплатно, без карты.
  2. Открой AI → Workers AI и нажми Use REST API.
  3. Create a Workers AI API Token → Create API Token → Copy API Token.
  4. Там же скопируй Account ID.

Свой текст

Вставь слова нашида или цитату: каждая строка станет отдельной фразой на видео. Подойдёт любой язык, арабский тоже.

Перевод под строками — необязательно

Каждая строка перевода встанет под строкой текста с тем же номером: например, русский под арабским. Пустая строка — без перевода.

«Подогнать под музыку»: ролик заиграет, а ты нажимай кнопку (или пробел) в начале каждой строки. «Расставить ровно» — строки сами поделят время, потом можно подогнать.

✦ ИИ-помощник

Пришли ролик, который понравился: расскажу, как он сделан — склейки, музыка, цвет, переходы, субтитры. А кнопка «Сделать похожий» настроит студию так же.

Образец нужен только для разбора и в твой ролик не попадёт. Можно прислать его и боту в Telegram.
