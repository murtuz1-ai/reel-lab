# Reel Lab — ready subtitle templates

Open this page through the local Reel Lab server:

```text
http://127.0.0.1:8765/ready-captions/index.html
```

Then:

1. Choose a video.
2. Press **«Распознать речь»** to create local subtitles, or choose an existing
   `.srt` file with timed subtitles.
3. Choose one of the ready template cards.
4. Optionally set placement and the two source template colors.
5. Press **«Собрать MP4»**, wait for the local browser export, then press
   **«Скачать MP4»**.

Speech recognition runs locally through the installed Reel Lab engine. The
template export runs locally in a current Chrome or Edge browser because it
uses its built-in WebCodecs renderer. See `NOTICE.md` for the exact source and
license boundary.
